Descriptif

Cage + poignée SmallRig pour appareil photo Sony Alpha 7R VI

Cage pour appareil photo avec poignée supérieure :
Facilite les prises de vue en contre-plongée sans effort.

Extension illimitée :
Permet d'installer des poignées, des microphones, des supports de moniteur et d'autres accessoires. Le rail NATO HawkLock intégré permet une fixation rapide des accessoires HawkLock, tels que les poignées latérales (4485), les poignées supérieures (4483) et les supports de moniteur (4487).

Verrouillage sécurisé en 4 points :
Garantit une fixation fiable votre Alpha 7R VI pour des images stables.

Plateau rapide Arca-Swiss intégré :
Permet de passer facilement d'une configuration à main levée à une utilisation sur trépied ou stabilisateur (compatible avec DJI RS 2 / RSC 2 / RS 3 Mini / RS 3 / RS 3 Pro / RS 4 Mini / RS 4 / RS 4 Pro / RS 5).

Serre-câble HDMI inclus :
Sécurise la connexion du câble pour une transmission de données stable.
