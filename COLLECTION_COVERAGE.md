# EDGE — Collection coverage and retail-source context

The scheduled workflow targets a three-hour cadence (`37 */3 * * *` UTC), increased from six hours. This reduces planned spacing relative to six-hour event measurement windows; GitHub scheduling delays/missed dispatches remain possible. No guaranteed exact-time collection is claimed. Coverage incidents are written into the archived report, without sending external messages. A newly observed incident/diagnosis also produces a GitHub Actions warning; unchanged archived incidents are not re-announced on every run.

The collector retains bounded controls: up to 16 total configured sources and 8 persistent research monitoring targets, with three rotating discovery probes per run unchanged. Existing monitored series are retained for continuity; newly verified targets fill remaining research slots. The former four-target cap was saturated. The cap change increases bounded coverage, not financial authority or purchase permission.

`coverage_history.py` runs after verified retail-event follow-up, before dossier manifest generation. Outputs: `collection_coverage.json`, `retail_source_context.json`, `coverage_report.md`. Missing event target windows are classified using archived source attempts and report timestamps: no archived run in window; source absent from archived runs; failed source requests; or conflicting follow-up/source evidence. Nearest actual successful captures, raw hashes and snapshot references are retained. Late captures never fill old target windows. No inference about the scheduler's technical root cause is made from absent archives.

Source context uses current-run EUR asking-price observations at most 24 hours old. Failures, stale quotes, indicative card indices, nonpositive/nonfinite prices and other currencies do not become fresh executable prices. One current observation per retailer is counted; extra pages do not add independent sellers. Price/state/source/time/evidence are shown separately. The lowest observed in-stock asking price excludes stockout offers. This is not a delivered price, resale value, liquidity or net margin. Mixed source availability is distinguished from a source-specific stockout. Even multiple observed stockouts do not establish a market-wide shortage.
