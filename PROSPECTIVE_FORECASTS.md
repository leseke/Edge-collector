# EDGE — Frozen retail forecast ledger

`forecast_history.py` runs after the retail analogue engine, before dossier manifest generation. It never imports monthly retrospective estimates as live forecasts. Outputs: `forecast_records.json`, `forecast_evaluations.json`, `forecast_report.md`. All are appended with each run on the isolated data branch.

The first issuance for (model source fingerprint, retail event ID, horizon) is immutable. It preserves actual creation time, earlier feature cutoff, evidence, source hashes, sample, probability or explicit abstention, target window, and canonical record checksum. The fingerprint covers the analogue, event-follow-up, probability and forecast code. Different model fingerprints produce separate records and scores; none overwrite an old model's issuance. Identical historical replays deduplicate; checksum errors and conflicting immutable copies stop the stage. Historical snapshots provide the external audit trail; checksums are integrity checks, not cryptographic signatures or protection against an actor able to rewrite the repository.

No issuance is backdated to event detection. Issuance must occur before the target time to be prospectively scorable. Late registration is recorded and excluded, even if the outcome had not yet been collected. Sparse samples are frozen as abstentions with null probability. Later changes to the recomputed analogue report do not replace an earlier issuance. An old forecast cannot acquire hindsight confidence.

The current target is source-declared IN_STOCK at the first valid target capture within six hours after 24/72/168 hours from detection. Outcomes require identical product, seller, source URL, currency, target and bounded observation time, plus evidence hash. Missing/unknown availability is never a negative trial. Observed outcomes after abstention are not predictions. Numeric, timely, measured binary forecasts receive Brier scores, grouped by model and horizon. A paired persistence baseline is 0 after an observed stockout and 1 after a restock. Calibration/independence and profitability are not established. Evaluations are recomputed from verified current follow-up evidence and archived as separate snapshots; immutable forecast records never change.
