## Measurement protocol
For each coherent delivery record scope, accepted outcomes, exact SHA, CI results, actual browser/integration checks, defects and rework, owner interventions required, elapsed active work when measured, and provider-reported token usage when available. Unknown metrics remain unknown. Do not infer tokens from response length or wall time from commit timestamps. Count an outcome as fully accepted only after relevant functional validation; distinguish code delivered from verified usability.
Compare similar slices, not raw commit counts or lines of code. Optimize verified outcomes per intervention and measured resource use, with no relaxation of quality gates. Track regressions and rework over subsequent deliveries. No composite score until sufficient comparable observations exist.
